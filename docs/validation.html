Evidence over claims

Prove the runtime loop.

A successful page load is not proof of payment, boot, execution, settlement, or cleanup. Test each boundary separately.

Measure bottlenecks

Capture verification, settlement, boot, first command, command, and release latency separately. Repeat at least five times and report median and p95. Compare cold and warm boots, output sizes, command duration, and concurrent session count.

Known gaps

  • Fixed-block billing is not per-second usage accounting.
  • Lease state is in process memory.
  • Refund reservation idempotency needs durable storage.
  • Concurrency and restart recovery require production evidence.
