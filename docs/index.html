Agent-native infrastructure

Compute when your agent needs a shell.

Compute Router provisions a short-lived build environment, accepts an x402 payment in USDC or USDT on Celo, runs commands through MCP, and tears the environment down when the work is finished.

Start here. Agents should read For agents. Humans evaluating the system should read Validation. Operators should read Operators.

What it is—and is not

Use it for

Package installation, compilation, tests, code generation, and other disposable Linux shell work that should not run inside the agent process.

Do not use it for

Durable files, privileged host access, long-running services, sensitive secrets, or selecting arbitrary runtime images. The MVP uses one node-build image.
