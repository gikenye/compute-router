Run your own instance

Operate a Compute Router deployment.

The repository is designed for operators who want to host the Go core and Cloudflare Sandbox adapter as separate services.

Requirements

  • Go 1.25 for the current module.
  • Node.js 20+ and npm.
  • Docker for the sandbox container build.
  • A Celo RPC endpoint, facilitator URL/API key, payout address, and adapter shared secret.

Run locally

cp .env.example .env
cp services/sandbox-adapter/.dev.vars.example services/sandbox-adapter/.dev.vars
make deps
make dev-adapter
# in another terminal
make dev-core
make smoke-test

The smoke test checks MCP negotiation and static serving. It does not submit a payment.

Deploy

make build-core
make deploy-adapter
make deploy-core-fly

Set the adapter secret as a Worker secret, not in a committed configuration file. Point SANDBOX_ADAPTER_URL at the deployed Worker and set AGENT_MCP_PUBLIC_URL to the public MCP endpoint.

Secrets and safety

Never commit keys. The core needs a payout address, not a payment-receiving private key. The refund operator key is a separate, tightly scoped exception and must be stored as a deployment secret.

Run the read-only production probe after deployment. Run paid validation only with a dedicated, explicitly funded wallet and a small ceiling.
